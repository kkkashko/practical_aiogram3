# Telegram Bot on Aiogram 3

Учебный Telegram-бот для студентов, демонстрирующий основы работы с aiogram 3:
команды, клавиатуры, FSM, обработка callback-запросов.

## Функции

- `/start` — приветствие и главное меню
- `/photo` — отправка фото
- `/survey` — опрос через FSM (имя, возраст, город, язык)
- `/menu` — инлайн-меню
- `/cancel` — отмена текущего действия
- `/ping` — проверка работы бота
